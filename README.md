# 🧭 WK Hub — พอร์ตรวมลิงก์การเรียนรู้

> **Firman Portfolio** — เว็บพอร์ตรวมเว็บไซต์ที่พัฒนาด้วยเครื่องมือ **No-Code**

---

## 🚀 คุณสมบัติหลัก

- รวมทุกลิงก์ไว้ที่เดียว — แสดงเว็บไซต์จาก Glide และ Google Sites
- ค้นหา & กรองได้ทันที — เลือกแท็ก/แหล่ง หรือค้นหาแบบเรียลไทม์
- Responsive Design — ใช้ได้ทั้งมือถือ แท็บเล็ต และเดสก์ท็อป
- เปิดลิงก์และคัดลอกได้ — ปุ่มเปิดในแท็บใหม่และคัดลอกลิงก์ได้ทันที
- ปรับแต่งง่าย — โค้ด HTML + CSS + JS ไม่ซับซ้อน

---

## 🛠️ โครงสร้างไฟล์

```

wk-hub/
├── index.html    # หน้าเว็บหลัก
└── README.md     # คำอธิบายโปรเจกต์

````

---

## 🖥️ วิธีใช้งาน

1. ดาวน์โหลดหรือโคลนโปรเจกต์
   ```bash
   git clone https://github.com/username/wk-hub.git
````

2. เปิด `index.html` ในเว็บเบราว์เซอร์

   > แนะนำให้เปิดผ่าน Live Server หรือ `python3 -m http.server` เพื่อให้ปุ่มคัดลอกทำงานได้เต็มที่
3. เลือก **แท็ก** หรือ **แหล่งข้อมูล** เพื่อดูเว็บไซต์ หรือพิมพ์ค้นหา

---

## 🖋️ การปรับแต่ง

* เพิ่ม/ลบเว็บไซต์ในส่วน `RESOURCES` ใน `index.html`
* แก้ไขแท็กใน `TAGS` และแหล่งข้อมูลใน `SOURCES`
* ปรับสีและสไตล์ที่ `:root` ใน CSS
